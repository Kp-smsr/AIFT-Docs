# Test Scripts

## Script Structure

- Metadata: Script ID, name, description, author, last updated
- Preconditions: Environment setup and required services
- Inputs: Test data and parameters
- Steps: Ordered executable actions
- Expected output: Assertions and success criteria
- Cleanup: Restore environment or data

## Script Execution Flow

1. Validate preconditions
2. Load test data
3. Execute steps
4. Verify expected outputs
5. Record evidence and cleanup

## Error handling

- Fail fast on unrecoverable errors
- Capture logs and artifacts for debugging
