# Overview

## What is AIFT

AIFT (Automated Intelligent Functional Testing) is a methodology and tooling approach that combines automation, test design intelligence, and evaluation to produce high-quality functional test artifacts.

## Documentation purpose

This documentation explains AIFT principles, artifacts, test design patterns, and evaluation criteria to help teams adopt and measure AIFT outputs.

## Overall architecture

- Input: Requirements, user stories, or system descriptions
- Processor: AIFT generation components (models, heuristics)
- Output: Test plans, test cases, test scripts, evaluation reports

## Major components

- Artifact generator
- Evaluation engine
- Test execution harness
- Reporting and traceability

## Workflow

1. Ingest requirements and context
2. Generate candidate test plans and cases
3. Review and refine artifacts
4. Execute selected test scripts
5. Evaluate results using the evaluation framework

## Expected outputs

- Structured test plans
- Executable test scripts
- Evaluation scores and observations
