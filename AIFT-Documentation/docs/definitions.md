# Definitions

This page defines key terminology used across the AIFT documentation.

| Term | Definition |
|---|---|
| AIFT | Automated Intelligent Functional Testing — a methodology combining automation and intelligent artifact generation. |
| CTX | Contextual baseline or an alternative test plan generation approach. |
| Test Plan | A high-level strategy document describing the testing approach, scope, and schedule. |
| Test Case | A specific, repeatable set of steps to verify a feature or behaviour. |
| Test Script | An executable automation script that performs the steps in a test case. |
| Evaluation Criteria | Measurable attributes used to judge artifact quality. |
| Artifact Quality | The degree to which an artifact meets clarity, completeness, and correctness standards. |
| Traceability | The linkage between requirements and test artifacts. |
| Risk Coverage | The extent to which identified risks are addressed by tests. |
| Automation Readiness | How suitable an artifact is for automation. |
| Execution Readiness | Whether a test case/script can be executed with available environments and data. |
| Deterministic Consistency | The repeatability and determinism of test outcomes. |
| Benchmark Alignment | The mapping of artifacts to evaluation benchmarks. |
| DoD | Definition of Done — criteria that must be satisfied for an artifact to be considered complete. |
