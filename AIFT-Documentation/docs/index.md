# AIFT Documentation

Welcome to the AIFT documentation site. This documentation provides guidance, references, and templates for Automated Intelligent Functional Testing (AIFT).

Provide a central, maintainable, and searchable source of truth for AIFT processes, artifacts, and evaluation.

## Getting Started

1. Install dependencies: `pip install -r requirements.txt`
2. Run locally: `mkdocs serve`
3. Edit or add files under the `docs/` folder and push changes to update the site.
